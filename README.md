# 💻 Usar en local

1. Ingresar al servicio a usar (orders)
```
cd ./src/services/{service_name}  
```

2. Levantar las funciones
```
npm run start  
```

# 🚀 Desplegar

1. Debemos estar en la raiz del proyecto
2. Configurar nuestras credenciales de AWS
3. Ejecutar el siguiente comando
```
npm run deploy
```
